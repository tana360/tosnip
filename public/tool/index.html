Install on this PC

Ctrl+V, and the AI sees the file

After a one-time install, press Print Screen or Win + Shift + S, then Ctrl + V in PowerShell, CMD, or Windows Terminal. You do not save the picture yourself, and you do not type its name. The helper writes a JPEG in the C:\ToSnip folder and types the path so an AI in that CLI can open it. Nothing is uploaded to the web.

Install once

  1. Open a normal PowerShell window. It does not need to run as administrator. If the terminal you use every day runs as administrator, read that section below first.
  2. Press the copy button, paste the command into PowerShell, and press Enter.
  3. When it succeeds, PowerShell prints that the helper is installed. The helper starts at once and opens itself every time you sign in to Windows.

This command downloads the helper into the LocalAppData\ToSnip folder, creates a Startup shortcut named ToSnip paste, and creates the picture folder at the root of the drive.

Inspect before you execute:

PowerShell 
# Read the script before you run itirm https://tosnip.com/install.ps1 | Out-File install.ps1; notepad install.ps1

This writes install.ps1 in the current folder and opens it in Notepad. When you have read it, run .\install.ps1 in that same window.

Each time after install

  1. Press Print Screen, or press Win + Shift + S and drag over the area you need.
  2. Click the command line in CMD, PowerShell, or Windows Terminal so that window is in front.
  3. Press Ctrl + V.
  4. A bar appears near that window while the picture is scaled and saved. The path is then typed at the cursor, and the bar goes away.

The helper runs when the clipboard holds a picture and the front window is a terminal. If you paste ordinary text, Ctrl+V still pastes that text.

If focus leaves the terminal while the file is being saved, the path is copied instead, and the bar tells you to press Ctrl+V again.

The bar near the window

  • Scaling, while the width is brought down to 1000 pixels at most
  • Saving, while the file is written to disk
  • Saved, with the path, when writing finishes. The bar stays briefly, then closes.
  • Same file, when the picture matches one that has not expired yet

If the save fails, the bar turns red and closes itself after the message.

Where the file is

The picture is saved as a JPEG with a 6-character name, in a folder named after this system at the root of the drive, for example C:\ToSnip\a1b2c3.jpg. That path is typed into the command line so a program on this PC can open the file at once.

If this PC does not allow a folder at the drive root, the helper stores pictures in LocalAppData\ToSnip\images instead. A path that contains a space is wrapped in quotes so it is ready to use in a command.

The folder contains tosnip.txt, a marker that this folder belongs to ToSnip. Uninstall uses it so a folder of the same name that was not created here is left alone.

The same picture, and the 5 minutes

If you paste the same picture while the previous file is still there and the 5 minutes are not up, the helper does not create a new file. It types the same path.

When the 5 minutes are up, the file is deleted. The old path no longer opens. A screenshot does not stay on this PC after you are done with it.

It starts on its own, and you can pause it

After install, the helper sits in the Windows system tray at the lower right, and it starts every time you sign in. The icon is the program icon, and the menu item is Exit.

Choose Exit to close it for this session. The next time you sign in to Windows, it comes back. If you started the helper from a visible window, Ctrl+C in that window closes it too.

If the helper is already running and you start it again, a message says the helper is already running.

When the terminal is an administrator

A window opened with Run as administrator cannot see typing from an ordinary program. If CMD or Windows Terminal was opened as administrator, start the helper as administrator too. Otherwise Ctrl+V may not type the path into the command line.

Uninstall

Open PowerShell and paste the command below. It stops the helper, removes the sign-in startup, deletes the files in LocalAppData\ToSnip, and deletes ToSnip pictures in C:\ToSnip. When it finishes, PowerShell prints that the helper will not start by itself again.

Only the 6-character files this system created are deleted. If the folder holds anything else, those files stay, and the folder itself is removed only when it is empty.
